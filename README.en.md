# Reza Ranjbar — portfolio website

This is my portfolio website, built with HTML and CSS. It brings together my MATLAB, PHP/MySQL, modelling, and engineering-study projects and builds on my original Persian university website.

## View locally

Open `index.html`, or run `python -m http.server 8000 --bind 127.0.0.1` in this folder and visit `http://127.0.0.1:8000`. No packages or build step are required.

## Publish

Use the repository name `reza05463.github.io`. Upload this folder's **contents** to the repository root. Under **Settings → Pages**, choose **Deploy from a branch**, **main**, **/(root)**, and save.

The site is configured for `https://reza05463.github.io/`. GitHub Pages needs to be enabled before it is available there.

The project links use my GitHub username, `reza05463`. If you reuse the site, update those links and the repository name for your own account.

## Content and attribution

The image-processing figures come from the MATLAB coursework demos. The MATLAB repository explains the image sources and what the results show. The CSS diagrams are illustrations. Each project page describes its scope, including the unfinished parts of the CPN model.

I use this site to share my university work and make the code and notes easier to find. Collaborators and research sources are credited in the relevant repositories.
