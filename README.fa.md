# وب‌سایت نمونه‌کارهای من

این وب‌سایت را با HTML و CSS برای معرفی کارهای دانشگاهی‌ام آماده کرده‌ام. پروژه‌های متلب، PHP و MySQL، مدل‌سازی و یادداشت‌های مهندسی را یک‌جا معرفی می‌کند و بر پایه وب‌سایت فارسی اولیه‌ام شکل گرفته است.

## اجرا روی کامپیوتر

فایل `index.html` را در مرورگر باز کنید. برای اجرا با وب‌سرور محلی هم می‌توانید دستور زیر را در پوشه پروژه اجرا کنید:

</div>

```text
python -m http.server 8000 --bind 127.0.0.1
```

<div dir="rtl">

سپس آدرس `http://127.0.0.1:8000` را باز کنید. این پروژه به نصب بسته یا مرحله ساخت نیاز ندارد.

## انتشار با GitHub Pages

1. نام مخزن را `reza05463.github.io` بگذارید.
2. محتویات این پوشه را در ریشه مخزن بارگذاری کنید.
3. از **Settings → Pages**، گزینه **Deploy from a branch** را انتخاب کنید.
4. شاخه **main** و پوشه **/(root)** را انتخاب و ذخیره کنید.

آدرس در نظر گرفته‌شده، `https://reza05463.github.io/` است. سایت پس از فعال شدن GitHub Pages و تکمیل انتشار در این آدرس در دسترس قرار می‌گیرد.

پیوند پروژه‌ها با نام کاربری من، `reza05463`، تنظیم شده‌اند. اگر از این قالب استفاده می‌کنید، نام مخزن و پیوندها را برای حساب خودتان تغییر دهید.

## درباره محتوا

تصاویر پردازش تصویر، خروجی دموهای متلب هستند. منبع تصاویر ورودی و توضیح نتایج در مخزن متلب آمده است. نمودارهای CSS برای توضیح مفاهیم هستند. در توضیح هر پروژه، محدوده کار و بخش‌های ناتمام، از جمله مدل چراغ راهنمایی، مشخص شده‌اند.

این سایت را برای معرفی کارهای دانشگاهی و دسترسی آسان‌تر به کدها و یادداشت‌ها استفاده می‌کنم. نام همکاران و منابع پژوهشی در مخزن مربوط به هر پروژه آمده است.
