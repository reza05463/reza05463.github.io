# Reza.Ranjbar — وب‌سایت رزومه شخصی من

این نمونه‌کار را با HTML و CSS آماده کردم تا پروژه‌های دانشگاهی و موضوعاتی را که یاد می‌گیرم معرفی کنم.



## دیدن وب‌سایت

- [نسخه فارسی](https://reza05463.github.io/fa.html)
- [English website](https://reza05463.github.io/)
- [اولین وب‌سایتم](https://reza05463.github.io/first-website/)

برای مشاهده روی کامپیوتر، فایل `index.html` یا `fa.html` را در مرورگر باز کنید. سایت جاوااسکریپت، چارچوب، نصب بسته یا مرحله ساخت ندارد؛ فقط HTML، CSS و تصاویر است.


## فایل‌ها

| مسیر | کاربرد |
|---|---|
| `index.html` | صفحه انگلیسی |
| `fa.html` | صفحه فارسی با چیدمان راست‌به‌چپ |
| `style.css` و `portfolio.css` | ظاهر مشترک و سازگار با اندازه صفحه |
| `assets/` | خروجی‌های متلب و آیکون سایت |
| `first-website/` | پنج صفحه قدیمی، فایل CSS و تصویر پروفایل |
| `.nojekyll` | نمایش مستقیم فایل‌ها با GitHub Pages |

## اولین وب‌سایتم

متن فارسی و طراحی سرمه‌ای اولیه حفظ شده. در نسخه منتشرشده، پیوند برگشت، تنظیم نمایش در موبایل و اصلاح کوچک منو اضافه شده‌اند. آدرس تماس قدیمی هم با صفحه گیت‌هاب جایگزین شده است. این بخش، یادگاری اولین پروژه کدینگ من است.

## انتشار یا به‌روزرسانی

مخزن فعلی **`reza05463.github.io`** را استفاده کنید. **Reza.Ranjbar** نامی است که روی سایت نمایش داده می‌شود؛ نام مخزن، آدرس فعلی سایت را حفظ می‌کند.

1. محتویات این پوشه را در ریشه مخزن بارگذاری کنید. پوشه‌های `assets/` و `first-website/` را به همان شکل پوشه نگه دارید.
2. در **Settings → Pages**، گزینه **Deploy from a branch**، شاخه **main** و پوشه **/(root)** را انتخاب کنید.
3. ذخیره کنید و پس از انتشار، صفحه فارسی، انگلیسی و آرشیو اولین سایت را باز کنید.
